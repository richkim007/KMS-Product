# Quantum Astro-Rhythm Lotto Generator

## Overview

An advanced lottery number generator that creates 5 sets of numbers based on a unique blend of user-specific data, including their zodiac sign and biorhythms, powered by a "quantum" algorithm for a fun, personalized experience.

## Project Outline

*   **HTML (`index.html`):** The main structure of the web page, including input fields for user data and a display area for 5 sets of lottery numbers.
*   **CSS (`style.css`):** Modern and engaging styles for the user interface, reflecting the mystical and scientific theme.
*   **JavaScript (`main.js`):** The core logic for:
    *   Accepting user's birthdate and zodiac sign.
    *   Calculating biorhythm cycles.
    *   Applying influences from zodiac signs.
    *   Generating 5 unique sets of 6 lottery numbers using the combined "Quantum Astro-Rhythm" algorithm.
